# Compression audit working notes

This file records audit-only findings that are not yet promoted into design policy or a qualified observation.

## Baseline judgment

At Observation 226, it is not justified to describe the production implementation itself as small. The narrower hypothesis that LOAM may still have a compact semantic information basis remains open.

The audit must distinguish:

```text
semantic basis size
implementation surface size
historical/research surface size
```

A reduction in one does not count as a reduction in another.

## Initial concrete suspects

- QuantityBasis-era production files remaining after zero-origin work displaced part of the practical role.
- multiplication of domain-specific publisher/history/frontier/persistence mechanics.
- executable and low-level CLI entrances that may have survived completed migration or qualification work.
- one-observation/one-workflow CI accumulation.

These are suspects only. No deletion follows from this note without the ordered audit.
