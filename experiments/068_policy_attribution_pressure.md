# Observation 068 — Is disposal attribution a fact or a policy-selected view?

## Question

Observation 067 established that aggregate holdings do not determine which acquisition-specific quantities a disposal consumes:

```text
aggregate holding
    !=
quantity-bearing disposal source relation
```

It deliberately stopped before calling that relation a `Lot` or deciding how it should be selected.

Observation 047 had already established a general selection result on revision-graph coverage: when several valid witnesses exist, an explicit policy can choose among them without changing the underlying graph.

The next external-accounting pressure therefore needs to be narrower than simply asking whether two policies can choose differently.

> When several quantity allocations are valid for the same physical acquisition/disposal facts, is a policy-selected allocation the same kind of information as an explicitly retained source relation?

This matters for fungible holdings. A bookkeeping method may assign disposed quantity to earlier or later acquisitions even when the physical Event facts themselves do not contain a unique answer to "which acquired units left?"

## Minimal bounded shape

The model keeps two acquisition-specific Effect-like identities:

```text
Earlier acquisition: 3 units
Later acquisition:   3 units

Disposal:             4 units
```

The same physical facts therefore permit several valid source allocations, including:

```text
3 + 1
2 + 2
1 + 3
```

Two experiment-local policies provide deterministic accounting attributions:

```text
PreferEarlier -> 3 + 1
PreferLater   -> 1 + 3
```

These names are deliberately weaker than FIFO/LIFO. Observation 068 does not import a tax or inventory method; it only supplies two opposite deterministic selectors.

Each world also carries an independent quantity-bearing relation:

```text
explicitConsumption : AcquisitionEffect -> Quantity
```

This relation stands for an explicitly retained source attribution or source-specific statement. The model does not assume in advance that it was generated by the policy.

A separate predicate states that relation only when needed:

```text
conformsToPolicy(world)
```

## Selected questions

The observation distinguishes three layers:

```text
physical acquisition/disposal facts
        |
        +---- permit several valid quantity allocations

policy
        |
        +---- computes one selected attribution

explicit source relation
        |
        +---- may agree with or differ from that policy output
```

The selected questions are:

1. can a policy-generated attribution be represented while conserving disposal quantity?
2. can opposite policies produce different quantity allocations over unchanged physical facts?
3. with the same policy, can two valid explicit source relations still differ?
4. can the same explicit source relation coexist with different policies?
5. can an explicit source relation disagree with the current policy attribution?
6. if both worlds explicitly state that their relations conform to the same policy, is the source relation then fixed?

## Probes

### Representative policy attribution

Can `PreferEarlier` produce the `3 + 1` allocation and can the explicit relation conform to it?

Expected: **SAT**.

### Opposite policies, different quantity attribution

Can unchanged physical facts support `3 + 1` under one policy and `1 + 3` under the other?

Expected: **SAT**.

This is compatible with Observation 047's general policy-overlay result, but here the selected object is a quantity-bearing relation rather than one winner identity.

### Same policy, different explicit relation

Can both worlds use the same policy while retaining different valid explicit source relations?

Expected: **SAT**.

If so, policy alone does not determine what an independently retained relation says.

### Same explicit relation, different policy

Can two worlds retain the same source relation while carrying different policies?

Expected: **SAT**.

If so, the relation does not reveal which policy is currently configured.

### Policy and explicit relation can disagree

Can a structurally valid explicit source relation differ from the current policy-generated attribution?

Expected: **SAT**.

This is the central semantic pressure. A policy output is not automatically historical provenance or authoritative source attribution merely because it is deterministic.

### Does policy determine explicit source relation?

Expected check result: **SAT counterexample**.

### Does explicit source relation determine policy?

Expected check result: **SAT counterexample**.

### Must explicit source relation always equal policy attribution?

Expected check result: **SAT counterexample**.

### Does the same policy determine the same policy-generated attribution?

Expected check result: **UNSAT counterexample**.

This confirms that the model's selector itself is deterministic.

### Same policy plus explicit conformance

If both worlds use the same policy and both explicitly satisfy `conformsToPolicy`, do their source relations agree?

Expected check result: **UNSAT counterexample**.

## Intended interpretation

If the expected results hold, the bounded distinction is:

```text
valid disposal allocation
    !=
policy-selected attribution
    !=
explicitly retained source relation
```

More precisely, the first arrow means the physical facts admit several valid allocations and policy supplies a selector. The second arrow means a deterministic selector does not by itself establish that an independently retained source relation was generated by, governed by, or historically identical to that selector.

A conformance statement can connect the layers when the application intentionally chooses that semantics:

```text
physical facts
    + policy
    + conformance
        -> selected explicit attribution
```

Without that extra semantic link, silently recomputing an old source relation from the system's current policy could rewrite historical meaning.

## Relation to Observation 047

Observation 047 already earned:

```text
underlying graph
    !=
selection policy
```

Observation 068 does not claim that result again. It applies the distinction to the quantity-bearing relation exposed by Observation 067 and asks a different question:

```text
policy output
    !=
independently retained source relation
```

This is important because a later accounting implementation might otherwise treat a configurable selection method as though it were the physical provenance of fungible units.

## Relation to the Practical Core

The practical core already has stable `EffectKey` identity, exact `Quantity`, and a deliberately policy-light `Allocation` / `RecipientAssignment` numeric layer.

Observation 068 does not reuse those modules automatically or add a disposal API. Similar mathematical shape does not establish identical domain semantics.

No Practical Core change is earned merely by the bounded distinction.

## Important boundaries

Observation 068 does not establish:

- that disposed fungible units have no physical provenance in every domain;
- that every explicit source relation is authoritative evidence;
- FIFO, LIFO, average-cost, specific-identification, tax, or inventory law;
- a practical disposal-selection policy type;
- policy identity, versioning, validity time, provenance, or correction;
- whether policy changes should affect only future disposals;
- how a historical attribution should behave when policy changes later;
- persistence for either policy or source allocation;
- gain/loss semantics;
- a Practical Core `Lot` type;
- one-to-one acquisition-to-practical-Effect semantics;
- that policy-generated attribution and source evidence can never intentionally be the same representation.

The last point matters: an application may explicitly define its source relation to be policy-generated. Observation 068 only says that equivalence is an additional semantic rule, not a consequence of the physical Event facts.

## Tool choice

**Alloy only.**

The question is structural independence between physical facts, a deterministic selector, and an independently retained relation.

TLA+ may become appropriate later if policy can change through time and an old disposal must retain its original attribution. That temporal question is deliberately left unasked here.
