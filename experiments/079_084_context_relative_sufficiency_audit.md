# Observations 079–084 checkpoint — Context-relative sufficiency

## Purpose

Observations 079–084 form one coherent sub-arc. They do not earn a generic
`Summary`, `Context`, `Evidence`, or new Practical Core framework.

The durable result is a recurring design law:

```text
later question / admitted vocabulary
    -> distinctions that must survive
    -> retained evidence sufficient for those distinctions
```

Sufficiency is therefore relative to what a later operation is allowed to
observe. There is no context-free smallest summary that LOAM should preserve
for every future question.

## Earlier owner of the general law

Observations 004, 005, and 029 already established the architectural form over
retained household history.

```text
history
  -> future operation vocabulary
  -> observable equivalence classes
  -> sufficient retained state
```

Observation 029 generalized the important monotonicity: a summary sufficient
for a larger admitted vocabulary remains sufficient for a smaller one, while a
newly admitted distinction may require additional memory.

Observations 079–084 do not replace that law. They pressure-test it at formal,
privacy, reuse, and cross-dimensional observation boundaries.

## What 079–084 add

### 079 — checker interpretation is context-relative

A raw `SAT`, `UNSAT`, or `SUCCESS` token does not by itself preserve what was
established. The checking contract and later interpretation question matter.

### 080 — epistemic strength is regime-relative

Bounded no-counterexample evidence and an unbounded theorem are not the same
claim. Scope, theorem premises, and checking regime are semantically observable.

### 081 — result reuse is later-question-relative

A retained result may answer one later correction shape and fail closed for
another. The later operation participates in applicability.

### 082 — privacy-safe projection may deliberately lose provenance

A sanitized aggregate can preserve structural pressure while intentionally
forgetting which private identities participate. That loss is safe only while
later questions do not pretend the forgotten provenance is still available.

### 083 — separate marginals can lose a joint question

```text
summary(A × B)
    -> summary(A) + summary(B)

summary(A) + summary(B)
    -/-> summary(A × B)
```

Two views may each answer their own one-dimensional questions while jointly
remaining too weak for a cross-dimensional question.

### 084 — even the repair is query-shape dependent

The final specimen made the boundary concrete:

```text
2 × 2:
  marginals + one joint anchor
      -> whole joint table

3 × 3:
  marginals + one joint anchor
      -/-> whole joint table
```

The qualified tool split was deliberate:

- Lean proved the unbounded exact-integer 2 × 2 implication;
- Alloy exhibited a bounded 3 × 3 counterexample;
- J exposed both sides as ordinary array reconstruction and ambiguity.

The important result is not the number `1`. The amount and arrangement of
cross-evidence sufficient for a later query can itself depend on query shape.
No universal anchor count or contingency-table ontology was earned.

## One common structure

The household-history and formal-observation arcs now share the same discipline:

```text
source world / history / formal run
        ↓
retained state or projection
        ↓
later question
        ↓
answer
```

A retained representation is sufficient only relative to the distinctions that
the later question can observe.

This is a design discipline, not a request for a new domain abstraction.

## Private realization pressure

The 084 boundary was also exercised through the existing private Plan-realization
shadow boundary:

```text
private canonical source
    -> private-plan-realization-shadow
    -> sanitized joint aggregate
    -> structural sufficiency check
```

For the observed private snapshot, separate marginals did not uniquely determine
the sanitized joint aggregate, and no single observed joint-cell anchor made it
unique. That was snapshot-specific reality pressure, not a universal theorem.
No private identities, dates, descriptions, quantities, coordinates, source
metadata, or raw source text were required in public research artifacts.
